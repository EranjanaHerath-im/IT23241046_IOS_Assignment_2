BookNest
BookNest is an iOS library management app built with SwiftUI. It supports both librarians and borrowers, with features such as book search, borrowing, barcode scanning, Core ML recommendations, and overdue notifications.
Features
Role-based login (Librarian / Borrower)
Search and filter books
Borrow and return books
Overdue notifications
ISBN barcode scanning (VisionKit)
Core ML book recommendations
Add, edit, delete books and cover images (Librarian)
Category management
Dashboard with statistics
Dark Mode / Light Mode
Custom animations and swipe actions
Requirements
Xcode 16 or later
iOS 17.0+
Real iPhone required for barcode scanning
How to Run
Clone the repository
Open `BookNest.xcodeproj` in Xcode
Select a simulator or real device
Press Command + R
Technologies
SwiftUI
SwiftData
VisionKit
Core ML
UserNotifications
Testing
Run tests with Command + U.
